This folder is optional. CommandoSquad3D works fully without any files here —
all materials fall back to procedural canvas textures generated at runtime.

Drop any of these in to upgrade the visuals (loaded automatically if present):
  camo.jpg           — teammate/enemy uniform camouflage pattern
  palm_leaf.png       — coconut tree frond texture (alpha-friendly PNG preferred)
  bark.jpg            — tree trunk bark texture
  concrete_wall.jpg   — building / ruined wall surface
  road.jpg            — asphalt street surface

File names are case-sensitive and must match exactly. Any missing or failing
file silently keeps the generated procedural texture, so the game never breaks.
