🧩 ১. গল্প: Rahim প্রথমবার real data খুলল

Nila একটা CSV file পাঠাল — jobs.csv — বাংলাদেশের কিছু tech job post। Rahim NumPy দিয়ে খুলতে গিয়ে দেখল ঝামেলা: এখানে তো সংখ্যা আর লেখা মিশে আছে — title (লেখা), salary (সংখ্যা), city (লেখা), experience (সংখ্যা)। NumPy তো সব একই dtype চায়!

Rahim: "আপা, এই data-তে তো column-এর নাম আছে, আর একেক column একেক ধরনের। NumPy দিয়ে এটা সামলানো তো কঠিন হয়ে যাচ্ছে।"

Nila: "ঠিক ধরেছ। NumPy বিশুদ্ধ সংখ্যার জন্য। কিন্তু real-world data table-এ column-এর নাম, মিশ্র type, missing value — সব থাকে। এই কাজের জন্যই বানানো হয়েছে Pandas। ভাবো এটা হলো Python-এর ভেতরে একটা super-powered Excel — কিন্তু লাখ লাখ row সামলাতে পারে, আর সবকিছু automate করা যায়।"

❓ ২. সমস্যা: NumPy array-তে column-এর নাম নেই

NumPy array দিয়ে real tabular data সামলাতে গেলে কিছু সমস্যা:

  • column-এর নাম নেই — data[:, 2] মানে কী? মনে রাখা কঠিন।
  • এক array-তে সব একই dtype — কিন্তু title লেখা, salary সংখ্যা।
  • missing value (ফাঁকা ঘর) সামলানো ঝামেলার।
  • "salary 50k-এর বেশি এমন সব job-এর city দেখাও" — এমন প্রশ্ন কঠিন হয়ে যায়।

Pandas এই সবগুলোই সহজ করে — কারণ এটা label (নাম) + mixed type + missing value একসাথে সামলায়।

📚 ৩. Pandas কী এবং কেন দরকার

Pandas হলো Python-এর সবচেয়ে জনপ্রিয় data manipulation library। এর দুটো মূল জিনিস: Series (একটা labeled column) আর DataFrame (নাম-সহ column-এর একটা table)। Pandas ভেতরে NumPy ব্যবহার করে, কিন্তু ওপরে label, mixed type, missing value handling ও হাজারো সুবিধাজনক function যোগ করে।

কেন এই tech? real-world structured data প্রায় সবসময় table আকারে আসে (CSV, Excel, SQL, API)। বাংলাদেশ ও বিশ্বজুড়ে প্রায় প্রতিটা data/ML job-এ Pandas চাওয়া হয় — এটা junior-দের জন্য একটা "must know" skill।

🪜 ৪. তিন Level-এ DataFrame বোঝা

Level 1 — সহজ intuition

একটা DataFrame হলো Excel বা Google Sheets-এর একটা sheet — উপরে column-এর নাম, বাঁয়ে row-এর নম্বর (index), আর প্রতিটা ঘরে একটা value। পার্থক্য: Excel-এ আপনি মাউস দিয়ে কাজ করেন, DataFrame-এ code দিয়ে — তাই এটা automate করা যায়, বারবার ঠিকভাবে চালানো যায়, আর লাখ লাখ row সামলায়।

Level 2 — technical ভাবে

DataFrame হলো একগুচ্ছ Series-এর সমষ্টি, যাদের একটা common index আছে। প্রতিটা column আসলে একটা Series — যার নিচে একটা NumPy array। তাই একটা column-এর হিসাব (যেমন df["salary"].mean()) আসলে NumPy-র গতিতে হয়।

Level 3 — engineer দৃষ্টিতে

engineer রা DataFrame-কে data pipeline-এর কেন্দ্রীয় object হিসেবে দেখে: raw data → DataFrame-এ load → clean → transform → model-এ ঢোকানোর মতো array-তে রূপান্তর। তারা df.info() আর df.head() দিয়ে যেকোনো নতুন data-র সাথে প্রথম পরিচয় করে।

📥 ৬. Data load করা (CSV, JSON)

import pandas as pd # CSV থেকে — সবচেয়ে সাধারণ df = pd.read_csv("jobs.csv") # বাংলা লেখা থাকলে encoding দিতে হতে পারে df = pd.read_csv("jobs.csv", encoding="utf-8") # JSON (API response) থেকে df = pd.read_json("jobs.json") # Excel থেকে df = pd.read_excel("jobs.xlsx") # হাতে বানানো (উদাহরণের জন্য) df = pd.DataFrame({ "title": ["Python Dev", "ML Engineer", "Data Analyst", "Backend Dev"], "salary": [40000, 90000, 45000, 70000], "city": ["Dhaka", "Dhaka", "Chattogram", "Sylhet"], "experience": [1, 3, 2, 4], })
বাংলাদেশি data-তে encoding="utf-8" প্রায়ই লাগে (বাংলা লেখার জন্য)। ভুল encoding দিলে "গার্বেজ" অক্ষর দেখাবে — এটা একটা common junior সমস্যা, তাই মনে রাখুন।

👀 ৭. প্রথম নজর: data-কে চেনা

নতুন কোনো data পেলে engineer রা প্রথমেই এই function-গুলো চালায় — এটাই "data-র সাথে হ্যান্ডশেক":

df.head() # প্রথম ৫ row — data কেমন দেখতে df.tail(3) # শেষ ৩ row df.shape # (row সংখ্যা, column সংখ্যা) df.columns # column-এর নামগুলো df.info() # প্রতিটা column-এর type ও কতগুলো non-null value df.describe() # সংখ্যার column-এর summary (mean, min, max, ...) df.dtypes # প্রতিটা column-এর data type df["city"].unique() # city-তে কী কী distinct value আছে df["city"].value_counts() # প্রতিটা city কতবার এসেছে
df.info() আর df.describe() — এই দুটো যেকোনো নতুন dataset-এ প্রথমেই চালানোর অভ্যাস করুন। info() missing value ও type ধরিয়ে দেয়; describe() outlier ও অদ্ভুত value-র ইঙ্গিত দেয় (যেমন salary-র max যদি ৪০ লাখ হয়, বুঝবেন কিছু ভুল আছে)।

🎯 ৮. Column ও row বেছে নেওয়া: loc বনাম iloc

# একটা column (Series হিসেবে) df["salary"] # একাধিক column (DataFrame হিসেবে) — দুটো bracket df[["title", "salary"]] # --- loc: label (নাম) দিয়ে --- df.loc[0] # index label 0 এর পুরো row df.loc[0, "salary"] # row 0, column "salary" df.loc[0:2, ["title", "city"]] # row 0-2, নির্দিষ্ট column (0,1,2 তিনটাই) # --- iloc: position (নম্বর) দিয়ে --- df.iloc[0] # প্রথম row (position 0) df.iloc[0, 1] # প্রথম row, দ্বিতীয় column df.iloc[0:2] # প্রথম ২ row (position 0,1 — 2 বাদ)
loc বনাম iloc — junior-দের সবচেয়ে বড় বিভ্রান্তি:
• loc = label (নাম) দিয়ে; আর slicing-এ শেষ সীমা অন্তর্ভুক্ত (0:2 মানে 0,1,2)।
• iloc = integer position দিয়ে; slicing Python-এর মতো শেষ সীমা বাদ (0:2 মানে 0,1)।
এই পার্থক্যটা interview-তে খুব জিজ্ঞেস করা হয়।

🔍 ৯. Filtering: শর্ত দিয়ে row বাছাই

মনে আছে NumPy-র boolean indexing? Pandas ঠিক সেটাই ব্যবহার করে, কিন্তু আরও পঠনযোগ্য উপায়ে:

# salary 50000-এর বেশি এমন সব job df[df["salary"] > 50000] # Dhaka-র job df[df["city"] == "Dhaka"] # একাধিক শর্ত — & (and), | (or), প্রতিটা শর্ত () তে # Dhaka-তে salary 50k-এর বেশি df[(df["city"] == "Dhaka") & (df["salary"] > 50000)] # Dhaka অথবা Sylhet df[df["city"].isin(["Dhaka", "Sylhet"])] # title-এ "Engineer" আছে এমন df[df["title"].str.contains("Engineer")] # শুধু নির্দিষ্ট column দেখা, filter করার পর df[df["salary"] > 50000][["title", "salary"]]
খুব গুরুত্বপূর্ণ: Pandas-এ and/or নয়, বরং &/| ব্যবহার করুন, আর প্রতিটা শর্তকে বন্ধনীতে () রাখুন। নাহলে error বা ভুল result পাবেন — এটা junior-দের এক নম্বর ভুল।

➕ ১০. নতুন column তৈরি

# 10% increment-এর পর নতুন salary df["salary_new"] = df["salary"] * 1.10 # বছরে salary (মাসিক × 12) df["yearly"] = df["salary"] * 12 # একটা শর্তভিত্তিক column — senior নাকি junior df["level"] = df["experience"].apply( lambda x: "senior" if x >= 3 else "junior" ) # আরও পরিষ্কার উপায় (vectorized) বড় data-তে দ্রুত: import numpy as np df["level"] = np.where(df["experience"] >= 3, "senior", "junior")

লক্ষ করুন — df["salary"] * 1.10 পুরো column-এ একসাথে হিসাব করছে (vectorized, NumPy-র মতো)। এটাই Pandas-এর শক্তি: Excel-এর সুবিধা + NumPy-র গতি।

🇧🇩 ১১. বাস্তব উদাহরণ: job dataset নিয়ে প্রশ্ন

import pandas as pd df = pd.DataFrame({ "title": ["Python Dev", "ML Engineer", "Data Analyst", "Backend Dev", "Frontend Dev", "ML Engineer"], "salary": [40000, 90000, 45000, 70000, 55000, 110000], "city": ["Dhaka", "Dhaka", "Chattogram", "Sylhet", "Dhaka", "Dhaka"], "experience": [1, 3, 2, 4, 2, 5], }) # প্রশ্ন ১: Dhaka-র job কয়টা? print(len(df[df["city"] == "Dhaka"])) # 4 # প্রশ্ন ২: ML Engineer-দের গড় salary? ml = df[df["title"] == "ML Engineer"] print(ml["salary"].mean()) # 100000.0 # প্রশ্ন ৩: সবচেয়ে বেশি salary-র job-টা কোনটা? print(df.loc[df["salary"].idxmax(), "title"]) # ML Engineer # প্রশ্ন ৪: অভিজ্ঞতা 3+ বছর, এমন job-এর title ও salary print(df[df["experience"] >= 3][["title", "salary"]])

দেখুন — মাত্র কয়েক লাইনে আমরা data থেকে বাস্তব প্রশ্নের উত্তর বের করলাম। এটাই EDA (Exploratory Data Analysis)-এর শুরু — data-কে প্রশ্ন করা।

🔍 ১২. একজন AI Engineer-এর দৃষ্টিতে Pandas

  • প্রথমে চেনা: নতুন data পেলে head(), info(), describe() — সবসময়।
  • Chaining সাবধানে: filter করে নতuন DataFrame বানানোর সময় .copy() ব্যবহার করে "SettingWithCopyWarning" এড়ানো।
  • Vectorized ভাবনা: apply দিয়ে row-loop-এর বদলে সম্ভব হলে vectorized operation (দ্রুত)।
  • Reproducible: data cleaning-এর প্রতিটা ধাপ notebook/script-এ লেখা, যাতে অন্যরা একই ফল পায়।

⚠️ ১৫. সাধারণ ভুল ধারণা

ভুল ১: filter-এ and/or ব্যবহার। → ঠিক: Pandas-এ &/|, প্রতিটা শর্ত ()-তে।

ভুল ২: loc আর iloc এক ভাবা। → ঠিক: loc = label (শেষ সীমা অন্তর্ভুক্ত); iloc = position (শেষ সীমা বাদ)।

ভুল ৩: df["a", "b"] দিয়ে multiple column চাওয়া। → ঠিক: দুটো bracket লাগে: df[["a", "b"]]।

ভুল ৪: filter করা DataFrame-এ সরাসরি value বসিয়ে original বদলানোর চেষ্টা। → ঠিক: নতুন DataFrame হলে .copy() নিন; original বদলাতে .loc[শর্ত, "col"] = value।

ভুল ৫: সব কাজে apply/loop। → ঠিক: সম্ভব হলে vectorized operation বা np.where — দ্রুত।

🎤 ১৬. Interview Prep

প্রশ্ন ১: loc আর iloc-এর পার্থক্য?
উত্তর: loc label দিয়ে বাছে (slice-এ শেষ সীমা অন্তর্ভুক্ত); iloc integer position দিয়ে (শেষ সীমা বাদ)।

প্রশ্ন ২: Series আর DataFrame-এর পার্থক্য?
উত্তর: Series একটা labeled 1D column; DataFrame হলো common index-এর অধীনে একাধিক Series-এর 2D table।

প্রশ্ন ৩: নতুন dataset পেলে প্রথমে কী চালাও?
উত্তর: head(), shape, info(), describe(), আর কিছু column-এ value_counts()।

প্রশ্ন ৪: একাধিক শর্তে filter কীভাবে?
উত্তর: df[(cond1) & (cond2)] — প্রতিটা শর্ত বন্ধনীতে, &/| দিয়ে যুক্ত।
